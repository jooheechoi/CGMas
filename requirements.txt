# Unofficial LAMMPS wheels (https://github.com/njzjz/lammps-wheel), built
# against MPICH on Linux and macOS and against Microsoft MPI on Windows.
# CGMas launches LAMMPS with `mpirun -np N python ...`, so the mpirun on your
# PATH must come from the SAME MPI implementation this wheel was built against.
# Mixing OpenMPI's mpirun with these wheels silently launches N independent
# serial runs instead of one parallel run.
#
# If you already have a LAMMPS build with the Python module enabled
# (`-D BUILD_SHARED_LIBS=ON -D PKG_PYTHON=ON`, then `make install-python`),
